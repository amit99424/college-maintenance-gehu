# 🏫 Campus Care

A modern web-based College Maintenance System built using **Next.js**, **Firebase**, and **Tailwind CSS**.
The system allows students and staff to report maintenance issues while enabling supervisors and administrators to manage complaints efficiently.

---

## 📌 Features

### 👨‍🎓 Student Dashboard
- Secure Login & Signup
- Submit maintenance complaints
- Upload complaint images
- Track complaint status
- View complaint history
- Profile management

### 👨‍🏫 Staff Dashboard
- Login & Signup
- Raise maintenance requests
- Upload images
- Track complaint progress
- Manage profile

### 👷 Supervisor Dashboard
- View assigned complaints
- Update complaint status
- Assign work
- Monitor pending and completed issues

### 👨‍💼 Admin Dashboard
- View all complaints
- Filter complaints
- Manage users
- Manage supervisors
- Track complaint analytics
- Update complaint status
